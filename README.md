# Lava Jato Efrain

Site institucional do Lava Jato Efrain. HTML/CSS/JS estático, sem build. Tema claro em azul e ciano, com
ilustração de carro e bolhas de espuma em CSS/SVG. Base derivada do site da Refritec Air; as regras próprias
ficam no fim do `styles.css`.

```bash
npx --yes serve . -l 6540
```

## ATENÇÃO: site montado com o mínimo de informação

A única fonte foi o contato do WhatsApp, que **não é conta comercial**: não tem nome, foto, descrição,
endereço nem horário. Só o número. O nome "Lava Jato Efrain" veio do nome do repositório.

| Campo | Valor |
|---|---|
| Nome | Lava Jato Efrain (do repositório `lavajato-efrain`) |
| WhatsApp / telefone | (92) 99492-5953 (`wa.me/559294925953`); o print mostra `9492-5953`, o texto usa o 9 do celular |

## Confirmar com o cliente

- **Nome e grafia:** "Efrain" ou "Efraim"? E se o lava jato tem outro nome comercial.
- **Serviços:** os 4 cards (lavagem externa, completa, limpeza interna, lavagem de motos) são o básico de um
  lava jato. Pegar a lista real e, se quiserem, os preços.
- **Endereço:** com o endereço dá para incluir mapa e "Como chegar" (DDD 92, Manaus e região).
- **Horário de funcionamento:** o FAQ manda consultar pelo WhatsApp.
- **Logo e fotos:** nenhuma disponível. A marca é texto + ícone de gota.
